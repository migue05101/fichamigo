# Fichamigo

Mascota virtual tipo Tamagotchi que vive de los deberes del hogar y del colegio.

- `fichamigo.html` — la app (fuente). `python3 build.py` genera `public/index.html`.
- `netlify/functions/api.mjs` — servidor: familias, emparejamiento de celulares, sincronización y fotos (Netlify Blobs).
- Se publica en Netlify conectando este repositorio (no necesita configuración extra).
